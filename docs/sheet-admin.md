# スプレッドシート管理メニュー

スプレッドシートを開くだけで上部に「SKY STANDARD」メニューが表示され、GAS エディタを開かずに日常の管理操作ができます。

## 仕組み

```text
スプレッドシート
  └ 管理メニュー用GAS（コンテナバインド, src/sheet-admin）
       onOpen() でメニュー表示 / 確認ダイアログ / 結果表示 / トリガー
       │  SkyStandard.adminRun(action, params)   ← ライブラリ呼び出し（開いた本人の Google 認証）
       ▼
  独立GAS（src/gas, Web アプリ兼ライブラリ, ID: 1zlkPtaZ…）
       assertAdmin_() で管理者確認 → 既存の業務処理（承認・再送・リッチメニュー等）を再利用
       スクリプトプロパティ（秘密情報）・キャッシュ・ロックは独立GASのものを共有
```

- 独立GASの関数はスプレッドシートから直接呼べないため、独立GASを**ライブラリ**として読み込んでいます。公開 Web アプリに管理用の入口は作っていません。Web アプリ（`doPost`）から `adminRun` には到達できません。
- 管理操作はすべて、実行者が `ADMIN_USERS`（独立GASのスクリプトプロパティ）に登録されているかを確認してから実行します。`ADMIN_USERS` が未登録の間は誰も実行できません（最初に必ず登録してください）。
- ライブラリとして呼び出せる関数は `adminRun`（管理者確認あり）と、冪等な定期処理・キャッシュ破棄だけです。業務処理の関数は非公開（末尾 `_`）にしています。
- 定期処理のトリガーは**独立GAS側**に作ります。スプレッドシート側の GAS にインストール型トリガーを作ると、シート編集者がスクリプトを書き換えて管理者の権限で実行できてしまうためです。
- 通知の送信・却下・再送・リッチメニュー更新・シート補完・トリガー設定の前には、確認ダイアログを表示します。
- 結果とエラーは、スプレッドシート上のダイアログに日本語で表示します。長い結果はスクロールできます。
- 管理メニュー用GASには秘密情報を置きません。

## メニュー構成

| メニュー | 項目 | 内容 |
|---|---|---|
| 初期設定 | シート列・設定行の補完 | 不足列・ID管理の不足キー・テンプレート（OFF）を追加し、`SPREADSHEET_ID` を保存。既存データは変更しません |
| | ID・URL設定チェック | ID管理の各キーを【OK／未設定／形式エラー】で表示。秘密情報の有無（値は非表示）と、機能ごとの不足設定も表示します。キャッシュも更新します |
| | LINE接続チェック | トークンの有効性、アカウント名、Webhook 設定、配信数を確認。任意で Webhook 疎通テストも実行できます |
| | ID管理の変更を反映（再読込） | 設定キャッシュを破棄 |
| LINE管理 | リッチメニュー登録・更新 | 登録内容を確認してから LINE に登録し、既定に設定 |
| | リッチメニュー設定確認 | 各ボタンの遷移先と、LINE 側の既定メニューを表示 |
| | 今月の配信数確認 | 配信数・上限・残り |
| 予約・通知 | 承認待ち通知を送信（選択中の行） | 「送信ログ」で選択した1行の文面を表示し、確認後に送信 |
| | 選択中の通知を却下 | 承認待ちの通知を送らずに却下 |
| | 失敗した通知を再送 | 対象件数を確認してから再送（重複防止キー付き） |
| | 通知テンプレート確認 | ON/OFF、未登録テンプレート、使えない変数 |
| システム管理 | トリガー設定 | 独立GASに「搭乗前日リマインド」「通知の再送」を作成（重複・旧版は整理） |
| | トリガー状態確認 | 独立GASのトリガー数と最終実行時刻を表示 |
| | 接続・設定診断 | シート・設定・管理者・LINE・トリガー・送信ログをまとめて診断 |

## 作成・反映方法

### 前提：独立GASのコードを最新にする

```bash
git checkout feature/line-system && git pull
clasp push                    # ルートの .clasp.json（rootDir: src/gas）
```

管理メニューは独立GASの「最新の保存内容（開発モード／HEAD）」を参照します。Web アプリのデプロイとは関係なく、`clasp push` した時点で反映されます。

### A. clasp で作成する場合（推奨）

```bash
cd src/sheet-admin
clasp create --type sheets --title "SKY STANDARD 管理メニュー" \
  --parentId 1pzu1_-X8-Y7AhAq4ctwgfliYnImkPe6sa4d_TBth1Es --rootDir .
# → src/sheet-admin/.clasp.json が作成される（.gitignore 済み）
clasp push --force            # Code.gs と appsscript.json（ライブラリ設定込み）を反映
```

`clasp create` が作成した `appsscript.json` を上書きする確認が出た場合は、リポジトリの内容で上書きしてください。

### B. 手動で作成する場合

1. スプレッドシートを開き、「拡張機能 → Apps Script」を選択します。スプレッドシートに紐づく新しいプロジェクトが開きます。
2. プロジェクト名を「SKY STANDARD 管理メニュー」にします。
3. 「ライブラリ ＋」を開き、スクリプトID `1zlkPtaZlrSOfKUVKw4rxDmaGB42-niVZtYdDlwSNusnmnn50BB1axmff` を追加します。
   - バージョン: **HEAD（開発モード）**
   - ID: **SkyStandard**（大文字・小文字も一致させる）
4. 「プロジェクトの設定 → appsscript.json をエディタで表示」をオンにし、`src/sheet-admin/appsscript.json` の内容に置き換えます。
5. `コード.gs` を `src/sheet-admin/Code.gs` の内容に置き換えて保存します。

> 開発モード（HEAD）のライブラリは、独立GASの**編集権限**を持つ人だけが使えます。管理者には独立GASの編集権限を付与してください。バージョンを固定したい場合は、独立GASで「デプロイ → 新しいデプロイ → ライブラリ」を作成し、`version` にその番号を、`developmentMode` に `false` を指定します。

## 初回認証

1. スプレッドシートを再読み込みすると、メニュー「SKY STANDARD」が表示されます。
2. 任意のメニュー（例: 初期設定 → ID・URL設定チェック）を選ぶと「承認が必要です」と表示されます。表示に従い、Google アカウントで許可してください。
3. 許可後、同じメニューをもう一度実行します。

| 要求される権限 | 用途 |
|---|---|
| スプレッドシートの表示・編集 | 管理台帳の読み書き |
| 外部サービスへの接続 | LINE Messaging API |
| スクリプトのトリガー管理 | トリガー設定 |
| スプレッドシート内のダイアログ表示 | 確認・結果表示 |
| メール送信 | 運営通知メール（ADMIN_EMAIL 設定時） |
| Google ドライブの閲覧 | リッチメニュー画像の読み込み |
| メールアドレスの表示 | 管理者確認 |

## 管理者の登録（最初に必須）

独立GASのエディタ →「プロジェクトの設定」→「スクリプト プロパティ」に `ADMIN_USERS` を追加し、管理者のメールアドレスをカンマ区切りで登録します（関数の実行は不要です）。

```text
ADMIN_USERS = owner@example.com, staff@example.com
```

管理者リストは、シート編集者が書き換えられないよう、シートではなくスクリプトプロパティで管理します。

## トリガー設定の仕組み

1. 「システム管理 → トリガー設定」で、管理者確認のうえ作成要求を独立GASに記録します（有効期限10分・1回限り）。
2. 管理メニューが Web アプリ（`GAS_WEBAPP_URL` に `?sync=triggers`）にアクセスします。独立GASが所有者の権限で、要求があればトリガーを作成します。このアクセスには認証情報も秘密情報も含めません。要求がなければ、Web アプリは何も作成しません。
3. Web アプリを未デプロイの場合は、独立GASのエディタで関数 `installTriggers` を1回だけ実行してください（代替手段）。

| 独立GASのトリガー | 頻度 | 内容 |
|---|---|---|
| `triggerFlightReminders` | 毎日10時台 | 翌日搭乗・予約確定の予約へ前日案内（1予約1回のみ） |
| `triggerRetryFailedSends` | 10分おき | 一時エラーの通知を再送（重複防止キー付き） |

ID管理シートを編集すると、シンプルトリガー `onEdit` が独立GASの設定キャッシュを破棄し、新しい値がすぐに反映されます。シンプルトリガーで実行できない環境でも、キャッシュは最大5分で更新されます。

## セキュリティ上の注意

- スプレッドシートの**編集者は、スプレッドシートに紐づく GAS も編集できます**。管理者がメニューを実行すると、そのスクリプトは管理者の権限で動きます。編集権限は信頼できる担当者に限定してください。
- 予約システム API のキーは、スクリプトプロパティ `RESERVATION_API_ALLOWED_HOST` に登録したホストにだけ送信します。ID管理シートの `RESERVATION_API_BASE_URL` が書き換えられても、キーは外部に送られません。

## トラブルシューティング

| 症状 | 原因・対処 |
|---|---|
| メニューが表示されない | 管理メニュー用GASが未作成か、`onOpen` がありません。ページを再読み込みし、拡張機能 → Apps Script で `Code.gs` を確認してください |
| メニューが2つ表示される | 管理メニュー用GASが2つ作成されています。拡張機能 → Apps Script のプロジェクトを1つにしてください（独立GASには onOpen を置いていません） |
| 「ライブラリ未設定」 | ライブラリ ID `SkyStandard` が未追加か、ID の綴りが違います |
| 「実行エラー … アクセス権」 | 実行者に独立GASの編集権限がない（開発モード）か、初回認証が済んでいません |
| 「権限がありません」「管理者が未登録です」 | 独立GASのスクリプトプロパティ `ADMIN_USERS` に実行者のメールアドレスを登録してください |
| 「設定が不足しています」 | 表示された設定キーを ID管理シート（ID・URL）またはスクリプトプロパティ（秘密情報）に入力します |
| 「SPREADSHEET_ID が未設定」 | 「初期設定 → シート列・設定行の補完」を実行すると自動で保存されます |
| ID管理を変えても反映されない | 「ID管理の変更を反映（再読込）」を実行するか、「トリガー設定」で編集検知トリガーを作成してください。リッチメニューは再登録が必要です |
| 【危険】秘密情報がシートにある | ID管理シートの該当セルの値を削除し、スクリプトプロパティに設定してください。システムはシート上の秘密情報を使いません |
| トリガー設定で「応答を確認できません」 | `GAS_WEBAPP_URL` が正しいか、Web アプリが「全員」でデプロイされているか確認してください。代替として独立GASのエディタで `installTriggers` を実行できます |
| トリガー状態が「想定より長く実行されていません」 | 独立GASの「トリガー」画面で失敗履歴を確認してください（所有者の権限が失効していないか） |
